# Відповідність умові

Позначка «готово» нижче означає наявність відповідного коду й фактичних артефактів. Демонстрація та відповіді під час захисту залишаються частиною оцінювання.

| Пункт | Артефакт | Стан |
|---|---|---|
| 1.1. Побудова FlameGraph | `scripts/linux/run_lab.py`, `render_flamegraph.sh`, сирі профілі, SVG, сценарій живої демонстрації | Підготовлено; показати на захисті |
| 1.2. Інтерпретація | `docs/REPORT.md`, `docs/DEFENSE.md` | Підготовлено |
| 2.1. GNU time verbose | 15 запусків у `results/linux-main/time` | Виміряно |
| 2.2. perf stat -d | 15 запусків у `results/linux-main/perf-stat` | Виміряно доступні події; LLC не підтримується |
| 2.3. perf record/report | Три профілі, звіти self/inclusive та стеки в `results/linux-main/profiles` | Записано й проаналізовано |
| 3.1. Енергія системи | Windows EMI: CPU package і DRAM під час роботи | Частково: виміряні ці домени, а не весь ПК з розетки |
| 3.2. Енергія виключно програми | Реальні доменні показники й matched-idle reference | Оцінено додатковий внесок; точний per-PID показник недоступний |
| 4.1. Асемблер до/після | `results/assembly`, `docs/ASSEMBLY.md` | Підготовлено |
| 4.1.1. AVX/SIMD | Фактичні AVX2 інструкції, контрольна scalar-збірка | Підтверджено |
| 4.2. Час та інші показники | `results/analysis`, `docs/REPORT.md` | Порівняно |
| 4.3. FlameGraph після оптимізації | Три SVG й порівняння стеків у звіті | Порівняно |
| 4.4. Енергія після оптимізації | Серія Windows EMI, повна доменна енергія й оцінка після віднімання фону | Порівняно в межах CPU package / DRAM |
| GitHub | Репозиторій `quadroex/os-lab2-performance-image-pipeline` | Підготовлено для перегляду; приватний доступ перевірити перед здачею |
| Захист / відео | `docs/DEFENSE.md` | Запис студента або особистий захист ще потрібен |

Зовнішнього ватметра користувач не має або не знає про його наявність. Повне споживання ПК не обчислювалося через TDP, припущення про блок живлення або довільні коефіцієнти. Питання про прийнятність обмеження до CPU package / DRAM для пункту 3.1 слід прямо обговорити під час захисту; цей репозиторій не гарантує повні бали за непроведене вимірювання.
