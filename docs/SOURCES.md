# Джерела

Код програми та скрипти підготовлено для цієї лабораторної з допомогою ШІ. FlameGraph — сторонній інструмент Brendan Gregg та співавторів; його авторство й ліцензія належать розробникам. Скрипт завантажує оригінальний код із зафіксованої ревізії.

- [CPU Flame Graphs](https://www.brendangregg.com/FlameGraphs/cpuflamegraphs.html) та [код FlameGraph](https://github.com/brendangregg/FlameGraph).
- [Приклади використання perf](https://www.brendangregg.com/perf.html).
- [Параметри оптимізації GCC](https://gcc.gnu.org/onlinedocs/gcc/Optimize-Options.html).
- [GNU time](https://www.gnu.org/software/time/).
- [Довідник інструкцій Intel](https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html).
- [Windows Energy Meter Interface](https://learn.microsoft.com/windows-hardware/drivers/powermeter/energy-meter-interface).
- [Luís Cruz: вимірювання енергоспоживання програм](https://luiscruz.github.io/2021/07/20/measuring-energy.html).
