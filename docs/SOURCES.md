# Джерела та походження

Вихідний код програми й сценарії вимірювання створено для цієї лабораторної. Код обробки зображення не скопійовано з чужого навчального розв’язку. Для підготовки використано допомогу AI (Codex); автор має перевірити відповідність правилам курсу та самостійно розуміти й пояснювати виконане.

Зовнішній інструмент FlameGraph — окремий проєкт Brendan Gregg та співавторів. Сценарій завантажує оригінал із GitHub із фіксацією ревізії; ліцензія та авторство залишаються в його каталозі. Цей інструмент не подається як власний код.
